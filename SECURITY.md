# Security Policy

## Supported versions

Only the latest published K.netagent release receives security fixes. Self-contained releases include a specific .NET runtime, so users should update the application when a new release is published.

## Reporting a vulnerability

Do not place API keys, tokens, private logs, session files, screenshots containing credentials, or exploit details in a public issue.

Use GitHub private vulnerability reporting when it is enabled for the repository. Otherwise, contact the repository owner privately through the GitHub profile before sharing reproduction details.

Include the affected version, Windows version, minimal reproduction steps, expected impact, and whether the issue requires an approved tool action. Redact all credentials and personal data.
